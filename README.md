# Form Validation

A responsive form-validation project built with HTML, CSS, and vanilla JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

The form uses JavaScript and the browser's Constraint Validation API to validate user input and provide helpful feedback.

## Features

- Email validation using HTML5 constraints
- Country-specific postal code validation (US, Canada, UK)
- Password length and confirmation validation
- Inline error messages that update as users correct their input
- Visual feedback using CSS `:user-valid` and `:user-invalid`
- Automatic focus on the first invalid field when submitting
- Responsive layout

## Built With

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

Clone or download the repository and open `index.html` in your browser. No additional dependencies or installation are required.

## What I Learned

This project helped me practice working with the Constraint Validation API, regular expressions, DOM manipulation, and JavaScript event handling.

I also gained experience writing reusable functions, using event delegation, debugging with browser Developer Tools, and refactoring code to improve readability and maintainability.

## Note

This is a frontend-only project focused on client-side validation. No information is submitted to a server.
